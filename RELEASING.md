# Releasing `@authlete/arena`

This SDK is **generated by Speakeasy** from the Arena OpenAPI spec. Do not hand-edit generated
files (`src/`, `docs/`, `README.md`, `USAGE.md`, `CONTRIBUTING.md`, …) — they are overwritten on
every generation. SDK method names and namespaces come from `overlays/method-naming.yaml`, applied
at generation time (not in the source spec).

## How it fits together

Everything is driven by this repo's single `.speakeasy/workflow.yaml`, which defines **two sources**:

- **`arena-api`** — the generation source: reads the spec **from the Speakeasy registry**, applies
  the overlay, and produces the SDK. This is what CI (and step ②) uses.
- **`arena-api-spec`** — the publish source: reads a local **`./openapi.yaml`** and pushes it **to
  the registry**. This is what you run in step ① (no overlay, so the registry stays pristine).

The only external artifact is `./openapi.yaml` (git-ignored — never committed).

```
./openapi.yaml ──①──▶ registry (arena-api) ──②──▶ this repo (SDK) ──④──▶ npm (@authlete/arena)
                                                        │
                                                  ③ commit & push to main
```

## Release steps

**① Publish the raw spec to the registry.** Drop the current Arena OpenAPI document in the repo
root as `openapi.yaml` (however you obtained it), then push it:

```bash
speakeasy run --source arena-api-spec
```

This is publish-only — it uploads the spec and touches nothing but `.speakeasy/workflow.lock`. It
does **not** generate the SDK.

**② Regenerate the SDK** from the registry (applies the overlay):

```bash
speakeasy run --skip-upload-spec
```

**③ Commit & push to `main`:**

```bash
git add -A && git commit -m "chore: regenerate SDK" && git push origin main
```

**④ GitHub Actions publishes to npm.** The Publish workflow fires on the `.speakeasy/gen.lock`
change and publishes `@authlete/arena`. Watch it:

```bash
gh run watch -R authlete-arena/arena-typescript
npm view @authlete/arena version
```

## Notes

- **Version** auto-bumps on spec changes; force one with
  `speakeasy run --skip-upload-spec --set-version X.Y.Z`.
- **Required repo secrets:** `SPEAKEASY_API_KEY` and `NPM_TOKEN`.
