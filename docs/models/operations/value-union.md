# ValueUnion


## Supported Types

### `boolean`

```typescript
const value: boolean = true;
```

### `number`

```typescript
const value: number = 128403;
```

### `number`

```typescript
const value: number = 1284.03;
```

### `string`

```typescript
const value: string = "<value>";
```

### `any[]`

```typescript
const value: any[] = [
  "<value 1>",
  "<value 2>",
  "<value 3>",
];
```

### `operations.Value`

```typescript
const value: operations.Value = {};
```
